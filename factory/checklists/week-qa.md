# Проверка недели

- [ ] Все семь дней имеют разные фокусы.
- [ ] Каждый день укладывается в 8–12 минут.
- [ ] Дни не повторяют один и тот же сценарий под разными названиями.
- [ ] Сложность растёт мягко и не требует навыка, который приложение ещё не объяснило.
- [ ] Контрольные задания можно сравнивать без ложного обещания объективной диагностики.
- [ ] Метрики недели вычисляются из реально сохранённых данных.
- [ ] Повторное прохождение не выдаёт полностью идентичный набор стимулов.
- [ ] Самооценка короткая и использует одинаковую шкалу.
- [ ] Итог недели объясняет прогресс и следующий шаг простыми словами.
- [ ] Все темы и тексты прошли человеческий просмотр.
