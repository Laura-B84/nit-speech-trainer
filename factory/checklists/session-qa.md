# Проверка одного занятия

## Блокирующие пункты

- [ ] Есть одна ясная цель дня.
- [ ] Каждый этап связан с этой целью.
- [ ] Реалистичный полный проход занимает 8–12 минут с учётом переходов.
- [ ] На каждом экране понятно одно следующее действие.
- [ ] До начала ответа видны время подготовки, длительность и ограничения.
- [ ] Пользователь понимает, когда идёт запись.
- [ ] Для записи предусмотрены остановка, повтор и понятное завершение.
- [ ] После каждого сохраняемого действия понятно, что произошло с результатом.
- [ ] Потеря доступа к микрофону не блокирует приложение без объяснения.
- [ ] В текстах нет неподтверждённых обещаний диагностики или объективной оценки речи.
- [ ] Задание можно выполнить без специальных знаний и без раскрытия чувствительных данных.

## Качество

- [ ] Первое действие начинается быстро, без длинного онбординга.
- [ ] Соседние этапы отличаются механикой или типом нагрузки.
- [ ] Примеры помогают понять правило, но не диктуют ответ.
- [ ] Тон взрослый, спокойный и поддерживающий.
- [ ] Есть запасной стимул для повторного прохождения.
- [ ] Финал показывает конкретный результат без перегрузки метриками.
