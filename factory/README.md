# Контент-фабрика «Нити»

Это лёгкий процесс подготовки тренировок. Он помогает отделить создание задания от его проверки и не является частью пользовательского приложения.

## Роли

| Роль | Результат |
|---|---|
| `training-architect` | Структура занятия, ритм, переходы и бюджет времени |
| `exercise-author` | Тексты заданий, темы и варианты сложности |
| `ux-editor` | Короткие и однозначные инструкции для экранов |
| `qa-red-team` | Независимая проверка по чек-листам и список конкретных рисков |

## Рабочий цикл

1. Выбрать один день и заполнить `templates/day.md`.
2. Проверить, что каждый раунд служит цели дня.
3. Написать контент и минимум один запасной вариант там, где задание может быстро исчерпаться.
4. Отредактировать инструкции как интерфейсные тексты.
5. Пройти `checklists/session-qa.md`.
6. На уровне недели пройти `checklists/week-qa.md`.
7. Передать человеку список решений и спорных мест.

## Главное правило

ИИ может спроектировать, написать и проверить черновик. Окончательное решение о продукте и контенте принимает человек.
