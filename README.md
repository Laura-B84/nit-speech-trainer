# НИТЬ

Приложение для коротких ежедневных тренировок речи.

Текущий фокус — первая неделя: знакомство с основными форматами упражнений и фиксация стартового уровня пользователя. Продолжительность одного занятия — 8–12 минут.

## Структура

- `content/` — исходные и рабочие версии программы занятий.
- `docs/` — продуктовые решения и спецификации.
- `factory/` — роли, шаблоны и чек-листы для производства контента.

## Текущий этап

Первая неделя собрана в работающем локальном приложении. В ней семь самостоятельных тренировок с отдельным прогрессом: связность речи, точные слова, выразительность, сокращение мысли, импровизация, история и итоговое испытание.

Каждый день включает короткий меняющийся разогрев, чтение вслух и практику свободной речи. При повторном прохождении чередуются два текста для чтения. Приложение поддерживает голосовые записи, 30-секундное добровольное прослушивание, их скачивание, таймеры, словесные спринты, самооценку и полный сброс прогресса для повторного тестирования. Тексты чтения подходят широкой взрослой аудитории, а задания свободной речи подстраиваются под выбранную цель.

Локальный адрес во время работы сервера: `http://127.0.0.1:4173/`.

Публичная демонстрационная версия: [laura-b84.github.io/nit-speech-trainer](https://laura-b84.github.io/nit-speech-trainer/).

Она публикуется через GitHub Pages из папки `dist/`. Голосовые записи остаются только в браузере пользователя и не отправляются в GitHub.
