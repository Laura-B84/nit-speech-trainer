# НИТЬ

Приложение для коротких ежедневных тренировок речи.

Текущий фокус — первая неделя: знакомство с основными форматами упражнений и фиксация стартового уровня пользователя. Продолжительность одного занятия — 8–12 минут.

## Структура

- `content/` — исходные и рабочие версии программы занятий.
- `docs/` — продуктовые решения и спецификации.
- `factory/` — роли, шаблоны и чек-листы для производства контента.

## Текущий этап

1. Сохранить исходную программу первой недели.
2. Спроектировать один эталонный день как полный пользовательский сценарий.
3. Проверить его ритм, инструкции и сохраняемые результаты.
4. После подтверждения распространить решения на остальные дни недели.

Рабочий прототип первого дня уже включает выбор цели, ежедневное чтение вслух, голосовые записи, таймеры, словесный спринт и самооценку. Тексты чтения остаются общими, а задания свободной речи адаптируются под выбранную цель.
