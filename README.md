# НИТЬ

Приложение для коротких ежедневных тренировок речи.

Текущий фокус — первая неделя: знакомство с основными форматами упражнений и фиксация стартового уровня пользователя. Продолжительность одного занятия — 8–12 минут.

## Структура

- `content/` — исходные и рабочие версии программы занятий.
- `docs/` — продуктовые решения и спецификации.
- `factory/` — роли, шаблоны и чек-листы для производства контента.

## Текущий этап

Первая неделя собрана в работающем локальном приложении. В ней семь самостоятельных тренировок с отдельным прогрессом: связность речи, точные слова, выразительность, сокращение мысли, импровизация, история и итоговое испытание.

Каждый день включает чтение вслух и практику свободной речи. Приложение поддерживает голосовые записи, таймеры, словесные спринты и самооценку. Тексты чтения подходят широкой взрослой аудитории, а задания свободной речи подстраиваются под выбранную цель.

Локальный адрес во время работы сервера: `http://127.0.0.1:4173/`.
